## [1.0.0] - 2026-09-08

### Added

- Initial release
- Support for Opencode, Claude Code, and Cursor
- 5 skills included:
  - `commit-messages` - Odoo R&D commit message format
  - `doodba-project` - Doodba 18.0 project conventions
  - `code-language-english` - English-only source code rule
  - `odoo-oca-modules` - OCA module structure and conventions
  - `one-module-per-commit` - One Odoo addon per commit rule
- CLI with multi-AI installation support
